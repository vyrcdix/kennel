03

Motion spec

Motion is gentle and tide-like — easing in slow, settling, never bouncing. All durations scale by --motion-scale (set it to 0 and the skin becomes motionless, matching the base). Temperature is never animated; chrome, forms and empty states stay still.

MomentDurationEasingWhat moves
Row select140mseasebackground + inset action bar fade; no layout jump
Hover lift120msease-outrow tint only — surfaces never translate
Toast in220msease-out8px rise + fade; auto-dismiss 4.2s
Pick back up360msease-in-outitem lifts off the shelf (fade + 6px up), then toast confirms; undo restores
Let the tide take it420msease-initem drifts down & fades — a release, not a snap-delete
Crystallize300msease-outbrief sea-glass bloom from the sacred-soft wash, then route to detail
Route / screen change180mseasecontent cross-fade; scroll resets to top
Day ⇄ night260mseasevariable cross-fade across the whole skin; no per-element flash
prefers-reduced-motion  All of the above collapse to an instant state change; the visible end-state is always the base style, so nothing is gated behind an animation.
04

Skin switch

The skin is a single class on the app root. Nothing else changes — same DOM, same routes, same keyboard model.

ConcernBehaviour
Selector.sk-tide on the root; add .night for cool mode. Workshop = absence of the class (or .sk-workshop).
WhereSettings → Appearance → Skin (live cards) and Light/Dark segmented control.
Persistencetide.theme = day | night; skin choice in the same store. Survives reload.
Day/Night defaultwarm day, cool night — per the brief; users may pin one.
Invariant across skinsroutes, components, item states (6), crystal types (5), temperature (4), thread hues (6), keyboard maps, copy keys.

held One sacred hue · one action accent · three families · four text-free temperature states · six quiet thread hues · mono stays load-bearing. changed Palette, radii (softer), density (roomier), display face (Bricolage), and the tide/sediment metaphor in copy & texture only.

05

Voice pass

The Life skin’s emotional register lives in its words — most of all in empty states and the verbs on destructive actions. The rule everywhere: kind, never alarm; recoverable, never lost; a choice, never a chore.

The release promise. Whenever something leaves a list — let go, filed, retired — the toast always offers Undo and notes it’s still in search. The brief’s object-permanence principle, in one sentence: “The tide took it. Still in search if you want it back.”
